# Excel Import Template Contract

## 1. Purpose

Tài liệu này chốt hợp đồng chính thức cho template Excel import MVP của SME Stock Sense. Mục tiêu là giữ template khớp schema hiện tại, tránh thêm cột không có đích lưu an toàn, và tách rõ phần mô tả template với phần triển khai upload/parse/import ở các task sau.

## 2. Official workbook sheets

Workbook chính thức:

- `00_HuongDan`
- `01_SanPham`
- `02_TonDauKy`
- `03_DanhMuc_ThamChieu`
- `04_Kho_ThamChieu`
- `05_GiaTri_HopLe`
- `06_QuyTac_KiemTra`

Không đưa `07_Source_Research` vào file tải xuống cho người dùng nghiệp vụ. Phần research chỉ để trong docs nội bộ.

## 3. Product sheet contract

Sheet: `01_SanPham`

Headers, đúng thứ tự:

1. `ma_san_pham`
2. `ten_san_pham`
3. `sku`
4. `ma_vach`
5. `don_vi_tinh`
6. `ma_danh_muc`
7. `gia_ban`
8. `ton_toi_thieu`
9. `ton_toi_da`
10. `trang_thai`

Required:

- `ma_san_pham`
- `ten_san_pham`
- `don_vi_tinh`
- `ma_danh_muc`

Mapping:

- `ma_san_pham -> san_pham.ma_san_pham`
- `ten_san_pham -> san_pham.ten_san_pham`
- `sku -> san_pham.sku`
- `ma_vach -> san_pham.ma_vach`
- `don_vi_tinh -> san_pham.don_vi_tinh`
- `ma_danh_muc -> danh_muc.ma_danh_muc`, rồi map sang `product.danh_muc_id`
- `gia_ban -> san_pham.price`
- `ton_toi_thieu -> san_pham.ton_toi_thieu`
- `ton_toi_da -> san_pham.ton_toi_da`
- `trang_thai -> san_pham.trang_thai`

Quy ước:

- `ma_san_pham` duy nhất trong file.
- `sku` duy nhất nếu có.
- `ma_vach` duy nhất nếu có.
- `gia_ban`, `ton_toi_thieu`, `ton_toi_da` không âm nếu có.
- `ton_toi_thieu <= ton_toi_da` nếu cùng có giá trị.
- `trang_thai` chỉ nhận `HOAT_DONG`, `NGUNG_HOAT_DONG`, hoặc để trống; để trống mặc định `HOAT_DONG`.

## 4. Opening stock sheet contract

Sheet: `02_TonDauKy`

Headers, đúng thứ tự:

1. `ma_kho`
2. `ma_san_pham`
3. `so_luong_ton`

Required:

- `ma_kho`
- `ma_san_pham`
- `so_luong_ton`

Mapping:

- `ma_kho -> kho.ma_kho`, rồi map sang `ton_kho.kho_id`
- `ma_san_pham -> san_pham.ma_san_pham`, rồi map sang `ton_kho.san_pham_id`
- `so_luong_ton -> ton_kho.so_luong`

Quy ước:

- Cặp `ma_kho + ma_san_pham` duy nhất trong file.
- `so_luong_ton` không âm.
- Nếu nhập tồn đầu kỳ cho sản phẩm mới, sản phẩm đó phải có trong `01_SanPham` hoặc đã tồn tại trong hệ thống.

## 7. Validation rules for later T158

### Product sheet

- Missing `01_SanPham` sheet -> error for `PRODUCT_ONLY`.
- Wrong header -> error.
- `ma_san_pham` is required.
- `ma_san_pham` must be unique in file.
- `ten_san_pham` is required.
- `don_vi_tinh` is required.
- `ma_danh_muc` is required and must exist in `danh_muc.ma_danh_muc`.
- `sku` must be unique if present.
- `ma_vach` must be unique if present.
- `gia_ban` must be `>= 0` if present.
- `ton_toi_thieu` must be `>= 0` if present.
- `ton_toi_da` must be `>= 0` if present.
- `ton_toi_thieu <= ton_toi_da` if both are present.
- `trang_thai` must be `HOAT_DONG`, `NGUNG_HOAT_DONG`, or blank.
- Blank `trang_thai` defaults to `HOAT_DONG`.

### Opening stock sheet

- `02_TonDauKy` is required only for `PRODUCT_WITH_OPENING_STOCK`.
- Wrong header -> error.
- `ma_kho` is required and must exist in `kho.ma_kho`.
- `ma_san_pham` is required and must exist in DB or in `01_SanPham`.
- `so_luong_ton` is required and must be `>= 0`.
- `ma_kho + ma_san_pham` must be unique in file.

## 8. Deferred columns and why

- `gia_nhap`: deferred because `san_pham` has only `price`, not purchase price.
- `don_gia_nhap`: deferred because opening stock cost is not modeled yet.
- `ngay_ghi_nhan`: deferred because import/transaction timestamp should be generated by system later.
- `ghi_chu`: deferred because current target tables do not expose a clear note field for product/opening stock import.

## 9. Import modes

- `PRODUCT_ONLY`
- `PRODUCT_WITH_OPENING_STOCK`

These are template modes, not DB state.

## 10. Scope boundaries for T155

T155 chỉ chốt hợp đồng template. Không làm:

- upload API
- download API
- parser Excel
- validation engine
- row error writer

- product update
- inventory update
- inventory transaction creation
